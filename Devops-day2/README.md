# DevOps Day 2 - Linux File Management & Permission

## What I Learned

- Linux Directories and files
- mkdir - create directories
- touch - create files
- cp - copy files
- mv - rename and move files
- rm - remove files
- cat - view file contents
- nano - edit files
- Linux file permission
- find - search for files and directories
- chmod - change permission
- Basic application and log structure
